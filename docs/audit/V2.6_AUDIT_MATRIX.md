# Audit matrix — IIP 2.5.1 → 2.6.0 (SaaS readiness)

Baseline: v2.5.1 (commit `e100d42`). Scope: what a hosted, multi-customer SaaS needs beyond the controlled
pilot of 2.5.1 — account lifecycle, billing, entitlements by subscription state, operations. Findings from
the 2.5.1 matrix (`V2.5.1_AUDIT_MATRIX.md`) that were already fixed are not repeated.

Severity: **H** security / data integrity / billing correctness; **M** reliability or customer workflow;
**L** hygiene. Status after 2.6.0: **FIXED**, **PASS** (verified, no change), **BLOCKED** (external),
**DOCUMENTED** (accepted limitation), **N/A**. Evidence: [T] automated test, [R] rehearsal in this
environment, [C] code review.
