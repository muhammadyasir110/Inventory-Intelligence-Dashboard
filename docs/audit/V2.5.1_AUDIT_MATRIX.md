# Audit matrix — IIP 2.5.0 → 2.5.1 (2026-10-24)

Scope: the v2.5.0 repository (commit `d3c08d6`) reviewed for a **controlled pilot** (a few organisations,
accounts created by an administrator, PostgreSQL behind HTTPS). Severity: **H** = wrong numbers, data loss,
cross-tenant exposure or misleading claims; **M** = degraded reliability or user confusion; **L** = hygiene.
Status: **FIXED** (changed and verified), **PASS** (reviewed and tested, no change needed),
**BLOCKED** (needs data, credentials, infrastructure or an external party), **DOCUMENTED** (accepted
limitation for the pilot, written in `docs/KNOWN_LIMITATIONS.md`), **N/A** (not required for this release
model, with reason).

Evidence categories are kept apart: **[T]** automated test in this repository, **[S]** synthetic
experiment, **[R]** rehearsal executed in this environment, **[C]** code review only. No finding relies on
authentic distributor data or on a user evaluation (neither exists).
