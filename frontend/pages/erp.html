Integrations & Data Exchange

How data gets in and out of the platform in this release.

Available now

  • File import (Data Upload): inventory snapshots and daily demand history from CSV or Excel, validated before anything is saved.
  • Report export: inventory snapshot as CSV or Excel, executive summary as PDF. Exports are limited to your organisation and protected against spreadsheet formula injection.
  • REST API: every screen uses the same documented HTTP API with bearer-token authentication (see docs/API.md). Your IT team can script imports and exports with it.

Not available in this release

There are no live connectors to ERP or accounting systems (for example SAP, Oracle, Microsoft Dynamics, Odoo or QuickBooks), to supplier portals, or to messaging services. Purchase orders created here are not sent to suppliers automatically. A connector would be built on the REST API above for a specific customer system and tested against it before being offered.
